# Nick Janocik Portfolio

Responsive personal portfolio with an independent software and automation consulting page at `/workwithme`, built for Vercel.

## Local Preview

```bash
npm run dev
```

Then open `http://localhost:5173`.

## Deploy

Vercel runs `npm run build` and serves `dist/`. The build preserves the original static portfolio and adds the isolated React freelancing page. See `WORKWITHME.md` for editing, embedded Calendly setup, and the contact flow.
